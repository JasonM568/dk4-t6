# <font color=5c3A93>交易查詢</font>

##### 簡要描述

- 查詢交易可供查詢交易狀態，包含信用卡、ATM轉帳、超商代碼交易、icash Pay交易、AFTEE先享後付、Line Pay交易、超商取貨付款、黑貓宅配貨到付款、街口支付交易

##### 串接前置作業
- 請於PAYUNi平台註冊會員，並且建立收款商店，取得商店代號<a href="#MerID">(MerID)</A>申請開通所需要的支付工具。
- 測試區：` https://sandbox.payuni.com.tw`
- 正式區：` https://www.payuni.com.tw`

##### 請求 URL
- 測試區：` https://sandbox-api.payuni.com.tw/api/trade/query`
- 正式區：` https://api.payuni.com.tw/api/trade/query`

- ※為配合國際組織與各收單銀行對網站SSL傳輸加密機制要求，敬請採用TLS v1.2以上協定。


##### 請求方式
- Http Post
- 請於header加入user-agent，建議內容為"payuni"

##### 串接金鑰
- 請登入PAYUNi平台檢視商店串接資訊取得 Hash Key及 Hash IV。

##### 請求参数
- Y=必要；C=選填

| 參數 | 必要 | 類型 | 說明 | 備註 |
| ----- | ----- | ----- | ----- | ----- |
| <div id="MerID">MerID</div> | Y | string | 商店代號 | 　　|
| Version | Y | string | 版本 | 固定 2.0 |
| EncryptInfo | Y | string | AES加密字串  | 請參考<br>[資料加解密](https://docs.payuni.com.tw/web/#/7/29 "資料加解密")<br>[資料加密陣列](https://docs.payuni.com.tw/web/#/7/56 "資料加密陣列") |
| HashInfo | Y | string | SHA256加密字串 | 請參考<br>[資料加解密](https://docs.payuni.com.tw/web/#/7/29 "資料加解密")<br>[資料加密陣列](https://docs.payuni.com.tw/web/#/7/56 "資料加密陣列") |

| 參數<br>(EncryptInfo) | 必要 | 類型 | 說明 | 備註 |
