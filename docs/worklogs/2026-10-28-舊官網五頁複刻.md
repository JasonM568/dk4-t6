## 做了什麼

- **Schema**：`KnowledgeArticle` 加 `contentHtml`／`sourceUrl`／`wpId @unique`（migration `20261028100000_knowledge_wp_import`，本機 deploy 驗過，無 public./auth.）。
- **消毒**：`src/lib/article-html.ts` 用 `sanitize-html` 白名單（標籤／屬性／`wp-*` class／iframe 只放行 youtube、embed.podcasts.apple.com、videopress；
  圖片音訊只收 https；src 被濾掉的 iframe／img 整個拿掉）。`components/article-html.tsx` 是全專案唯一的 dangerouslySetInnerHTML（測試鎖住）。
- **匯入**：`scripts/import-wp-knowledge.ts`（預設 dry-run、遠端 DB 要 `--allow-remote`、以 wpId upsert、8 路並行）。
  踩到兩個坑：① 摘要 `slice(0,120)` 把 emoji 切成落單 surrogate → Prisma `InvalidArg: unexpected end of hex escape` 整批失敗（改 code point 截字＋清落單 surrogate）；
  ② cat38 那批 `_fields` 沒帶 `date_gmt` → Invalid Date（改用 `date`＋08:00 備援）。本機 2,168 篇全進。
- **頁面**：`/about`（理念＋3 張照片 → 三個數字 → 六特色 → 院長）、`/lecturers`（合照＋6 卡）、`/testimonials`（22 支 reel 用 `instagram.com/reel/<code>/embed/` iframe，
  不載 embed.js，sandbox＋lazy）、首頁加 `ChancellorIntro compact`（與 /about 共用同一份文案）、`/knowledge` 改名「院長乾貨區」：六分類頁籤（`?cat=`）＋每頁 24 篇分頁＋
  非會員也看得到訂閱文章卡片（🔒）、文章頁有 contentHtml 走 ArticleHtml 否則 RichText、鎖頁帶登入與回列表。
- **註冊表**：`SITE_PAGES` 加 about／testimonials，knowledge 標題改「院長乾貨區」；後台分頁管理自動多兩個開關。
- **CSP（report-only）**：img-src／media-src 加舊站 CDN；frame-src 加 podcasts／videopress／instagram。
- **圖片**：15 張 webp/png 上傳 `course-assets/site/…`（`scripts/upload-site-images.ts`）；6 個 SVG 圖示 bucket 不收 → `public/site/about/`。
  院長照片本身右下角已印名牌，不再疊字。
- **後台**：知識專欄列表只取最近 100 篇、不帶 contentHtml（2,000 篇整表丟 client 會爆）；匯入文章卡片標「舊站匯入」並說明內文不可在此改。
- **測試**：`scripts/test-site-pages-clone.ts` 55 項；idor 29／rbac 77／course-access 35／check:actions 全綠；tsc／eslint 乾淨。

## 第二輪：新聞速報不搬＋媒體鏡像到 Storage（同日稍晚）

- Jason 問「9.3G 檔案太大了，我要刪減文章，乾貨區的文章大多是新聞圖片，對嗎？」。用本機匯出算：**新聞速報 711 篇佔 34,822 張（99%）**，
  平均每篇 49 張新聞截圖、一半以上內文零字；其他五個分類合計只有 396 張內文圖＋1,408 張封面（HEAD 實測 355MB）＋72 段 mp3／2 份 PDF（66MB）。
- Jason 拍板：**排除新聞速報、其餘圖片複製到 Storage**（Supabase 是 Pro 方案）。
- 做法：
  - `import-wp-knowledge.ts`：`EXCLUDED_WP_CATEGORY_IDS={31}`，`loadExport` 直接不載；`--apply` 先 `deleteMany` 先前匯入過的排除分類文章（本機那 711 篇就是這樣清掉的）。
    `KNOWLEDGE_CATEGORIES` 拿掉 news；標題【新聞速報】不再歸類。
  - 新腳本 `scripts/mirror-wp-media.ts`：`collectMediaUrls`（img／audio／source 的 src＋封面＋舊 CDN 上的燈箱原檔連結）→ 下載 → 上傳 `course-assets/knowledge/wp/<uploads 相對路徑>`
    （非 CDN 主機或怪字元走 `ext/<sha1>`）→ 寫 `<資料夾>/media-map.json`；失敗寫 `media-map-failed.json`、匯入時維持原網址。預設 dry-run 只 HEAD 統計。
  - 匯入時 `rewriteMediaUrls` 整段網址替換內文＋封面；dry-run 印 `postsStillOnOldCdn` 看還有幾篇連舊站。
  - bucket `course-assets` 的 allowed_mime_types 加 `audio/mpeg`（SQL，為了 72 段 mp3）。
- 鏡像結果：見下方「本機驗證」。失敗的只有 Facebook／Google 的外部圖（簽名過期 403／404），本來就抓不到。
- 測試：`test-site-pages-clone` 55 → 64 項（排除分類、loadExport、collectMediaUrls、rewriteMediaUrls、storageKeyFor 穿越與非 ASCII、封面改寫）。
